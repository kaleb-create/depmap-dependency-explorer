Scoring Model (Tetlock-Inspired)

V1 emphasizes calibration, probabilistic thinking, and accountability.

Binary Bets

Each forecast maps to P(Yes). Score uses Brier:

Score = (1 - (P(Yes) - Outcome)^2) * 100

Outcome is 1 for Yes and 0 for No.

Numeric Bets

You submit a point estimate plus confidence. V1 combines distance accuracy and confidence calibration:

RelativeError = |Estimate - Actual| / max(|Actual|, 1)
DistanceComponent = max(0, 1 - RelativeError)
Hit = 1 if RelativeError <= 10% else 0
ConfidenceComponent = 1 - (Confidence - Hit)^2
Score = (0.65 * DistanceComponent + 0.35 * ConfidenceComponent) * 100

Multiple Choice Bets

You choose one option plus confidence. Score is binary-style against the winning option.

Leaderboard

Leaderboard rank uses average score across each user's resolved forecasts.
